# 2026-10-07 업무 사전 개편

## 설계

기존 따뜻한 종이색·테라코타 포인트·한국어 산세리프·Phosphor Bold 아이콘을 유지했다. design-taste-frontend와 redesign-existing-projects의 기존 제품 우선 원칙을 적용했다. 방향은 업무 중 즉시 조회하는 개인 사전이며, 디자인 변수는 variance 4 / motion 2 / density 6으로 잡았다. 기존 화면의 큰 히어로, 큰 발견 카드, 반복 단어 목록을 압축했다.

## 변경

홈·설정은 화면 높이에 맞춰 간격과 배치를 조절한다. 낮은 모바일에서는 발견 카드 두 개를 전환 탭으로 보여 주며 두 기능과 새로고침을 모두 유지한다. 본문을 잘라내는 스크롤 잠금은 사용하지 않는다. 상세·검색·긴 기록 목록은 자연스럽게 스크롤된다.

첫 시작에서 업무 분야와 다른 관심 분야를 복수 선택한다. 직무·업무 환경·자주 하는 일이 상황별 사전 바로가기에 연결되고, 용어 친숙도와 간격 선택은 실제 읽기 화면에 반영된다. 계정/클라우드 동기화는 추가하지 않았으며 모든 설정은 로컬 브라우저에 보관한다.

메모·업무별 모음·단어장 검색과 CSV·문서 속 용어 찾기·뜻 비교·최근 기록·통합 JSON 백업을 추가했다. 학습 UI를 제거하고 기존 기록은 백업에 보존한다. 기존 스크롤 복원 로직을 유지한다.

분야 순서는 마케팅·광고, 개발·IT, 패션·섬유, 영상·촬영, 디자인, 인사·재무, 업무 공통이다.

## 데이터

인사·재무 320개를 새로 작성했다. 16개 주제별 20개씩이며 각 뜻과 예문은 개별 작성했다. 10개는 직접 열어 확인한 고용노동부·국세청·국민연금공단·IFRS 자료와 연결했다. 310개는 일반 지식 기반이며 전문 감수나 외부 확인을 주장하지 않는다. 세율·법정 일수를 고정하지 않았다.

신규 분야와 공통 분야의 인사팀·회계팀·직급·직책·CFO·피플팀·온보딩·미결은 같은 개념으로 묶어 다른 의미 카드의 오분류를 방지했다. 리텐션과 AP의 실제 분야별 차이는 유지했다. 짧은 한국어 검색어가 띄어쓰기를 가로질러 다른 단어와 우연히 맞는 문제도 수정했다(가편 → 평가 편향).

기존 2,125개 뜻의 편집 검토 서명은 유지하고 신규 320개에만 검토 기록을 추가했다. 전체 2,445개가 검토 기록과 일치한다.

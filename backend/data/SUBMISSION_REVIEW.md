# 첨부 후보 목록 선별·수정 기록

검토일: 2026-09-16. 광고·개발·촬영 중심 첫 목록과 추가로 전달받은 두 목록, 총 세 자료를 검토했습니다. 첨부 문장은 후보 제안이며 출처나 현업 감수로 취급하지 않습니다.

## 반영 결과

- 기존 1,765개 → 1,970개 분야별 뜻: 새 뜻 205개, 기존 항목 삭제 0개.
- 기존 20개 항목에 새 별칭 36개 연결. 별칭은 단어 수에 합산하지 않습니다.
- 새 뜻 중 27개는 공개 원문을 연결했고, 178개는 확실히 설명할 수 있는 일반 지식을 직접 작성했습니다. 후자는 외부 출처 미첨부로 표시합니다.
- 공통 업무 표현은 업무 공통에 두며, 다른 분야의 전문 공정을 패션 등에 복사하지 않았습니다.
- 기존 ID·뜻·예문·기록 연결을 유지했습니다. 검토 중 발견한 광고 PT의 잘못된 주제 데이터 형식도 ‘대행사 제안’으로 수정했습니다.

## 채택·수정 기준

1. 뜻이 안정적이고 업무 이해에 도움이 되는 개념을 채택합니다.
2. 같은 개념의 표기·활용형은 별칭으로 연결합니다. 기존에 있는 정의는 후보 문장으로 덮어쓰지 않습니다.
3. 약자가 같아도 의미가 다르면 구분합니다. GTM은 시장 진출 전략과 구글 태그 매니저를 별도 항목으로 검색합니다.
4. 과도한 비하, 감정적 불평 문장, 원인을 임의로 단정한 사고명, 통용 근거가 불분명한 은어는 제외하거나 보류합니다. 보류는 해당 표현이 어느 현장에서도 쓰이지 않는다는 단정이 아닙니다.
5. 예문·정의는 직접 다시 작성하고, 적용 범위나 혼동할 개념은 메모로 설명합니다.

# 분야·뜻·예문 전수 편집 검토

검토일: 2026-09-16

기존 2009개 뜻을 분야·정의·예문 단위로 검토했습니다. 같은 내용의 항목은 묶어서 읽고 각 분야에서의 쓰임을 비교했습니다. 이 검토 직후 1947개 뜻이었습니다. 이후 회의 표현 추가는 [별도 기록](MEETING_TERMS.md)에 정리했습니다.

기존 항목 중 정의 22개, 예문 332개, 주석 22개, 주제 304개를 수정했습니다. 변경 수는 서로 겹칩니다.
기존 항목 74개는 전문 분야 또는 업무 공통으로 통합했고, 기존 상세 링크·저장·학습 ID를 리디렉션으로 유지합니다. 키카피·심지 들뜸 2개 개념과 통합 목적의 업무 공통 10개 항목을 추가했습니다.

## 검토 기준

- 같은 단어라도 개념이 다르면 뜻·영문·별칭·검색 문장·예문·주석·출처를 함께 검토합니다.
- 개념이 같고 실제 협업에서 쓰이면 같은 정의를 유지합니다. 분야마다 문장을 다르게 쓰는 것 자체가 새 의미의 근거는 아닙니다.
- 패션 브랜드 마케팅과 화보 협업, 광고의 촬영·후반 협업, 디자인의 모션 작업은 유지합니다. 모든 직무가 그 용어를 쓴다는 뜻은 아닙니다.
- 예문은 직접 작성한 설명용 문장입니다. 실제 회사에서 인용한 발화로 표시하지 않습니다.
- Microsoft·React·MDN·Figma·Adobe 공식 자료로 주요 개념을 확인했습니다. 모든 용어를 새로 웹 검증하거나 업계 전문가가 감수한 것은 아닙니다. 외부 근거 없는 뜻은 계속 일반 지식 기반으로 표시합니다.

## 재발 방지

`editorial_audit.py`에서 (분야, 표제어)를 키로 뜻·예문·주석을 관리합니다. `scope_audit.py`에는 개별 분류 판단을 기록합니다.

`reviewed-meanings.json`은 공개 항목 전체의 검토 결과와 내용 해시를 보관합니다. 빌드는 이 파일을 자동 갱신하지 않습니다. 변경·추가 후 내용 검토 없이 배포 데이터만 바뀌면 검사가 실패합니다. 해시는 변경 감지용이며 문장의 정확성을 자동 판단하지 않습니다.

원본 후보를 추가할 때는 뜻과 예문을 분야별로 검토하고 해당 항목의 검토 기록만 갱신하세요. 테스트 통과를 위해 원문을 검토하지 않은 채 전체 해시를 재생성하지 마세요.

# 회의 용어·표현 확장

2026-09-16 · 분야별 새 뜻 178개 · 표제어 이름 167개 추가

기존 1947개 뜻을 보존하고 17개 기존 항목의 별칭 32개를 보강했습니다. 현재 사전은 2125개 뜻입니다.

## 편집 기준

- 광고·개발·패션·디자인·영상의 회의 목적과 검토 대상을 따로 정하고 예문을 개별 작성했습니다. 일반적인 논의·일정 표현은 업무 공통에 둡니다.
- 같은 표제어라도 앞단·뒷단·논리·밸런스 등은 해당 분야의 뜻과 주석을 구분합니다.
- 이미 같은 뜻이 있는 오너→담당자, 크리에이티브 브리프→브리프, 물량 배분→배분, 세이프티 테이크→백업 촬영은 별칭으로 연결합니다. 잠시 생성된 중복 항목의 상세 ID도 기존 뜻으로 연결합니다.
- 개발 앞단·뒷단을 프론트엔드·백엔드와 무조건 동일시하지 않습니다. 패션 드롭 출시는 안건을 제외한다는 드롭과 별개의 뜻입니다.
- 같은 분야에서도 RTB의 입찰/믿을 근거, PPM의 화보 촬영/의류 생산 전 회의를 구분합니다.
- 이름이 붙은 회의 외에도 논리 잡기·답답하다·힘주다·점프하다·타이트하게 등 실제 피드백의 표현과 활용형을 포함합니다.
- 새 예문 178개는 모두 직접 작성했으며 서로 같은 예문을 복사하지 않았습니다.
- 이 문서는 현재 앱의 5개 전문 분야와 업무 공통을 대상으로 한 추가 수록 기록입니다. 모든 회사의 모든 표현을 빠짐없이 확보했다는 목록은 아닙니다.
